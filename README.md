# Student Performance Analysis & Prediction

## Overview
This project analyzes student data to identify factors affecting academic performance and builds machine learning models to predict final grades.

## Data Cleaning
- Removed duplicates
- Checked missing values
- Converted categorical variables

## Exploratory Data Analysis
- Study time vs performance
- Failures vs grades
- Absences impact
- Correlation analysis

## Machine Learning
- Decision Tree Regressor
- Random Forest Regressor
- Model evaluation using MSE & R² score

## Key Insights
- Study time positively impacts performance
- Failures and absences negatively affect grades
- G1 & G2 are strong predictors of final grade

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
